This app sends through EmailJS. The mailbox you connect in EmailJS (Gmail, Outlook, etc.) is the actual From address. The sender field below is used as Reply-To, so replies go to you.

  1. Create a free account at emailjs.com.
  2. Add an Email Service and connect the Gmail/Outlook account that should send the campaign.
  3. Create a template whose To field is {{to_email}}, subject is {{subject}}, Reply-To is {{reply_to}}, and body includes {{message}} (optional: {{from_name}}).
  4. Paste your Public Key, Service ID, and Template ID below. They are saved in this browser only.

Recipients reply to this address. The EmailJS connected mailbox still appears as the From address.

Paste addresses separated by commas, spaces, or new lines. Or upload a .csv / .txt file — every valid email in the file is extracted.
