Email service

Not configured

EmailJS is already set in config.js. Campaign users do not need to enter keys. Edit that file to change them.

Signing up for EmailJS with events@techhubafrica.org only creates the EmailJS login. Mail is actually sent by the Email Service you connect. For cPanel, that must be Custom SMTP using the same mailbox, not Gmail.

  1. In cPanel → Email Accounts → Connect Devices for events@techhubafrica.org, copy the outgoing SMTP host (often mail.techhubafrica.org or the server hostname).
  2. In EmailJS → Email Services → Add Service → choose SMTP / Custom SMTP. Username: the full address events@techhubafrica.org. Password: that mailbox password. Port 465 (SSL) or 587 (TLS). Save and run the connection test.
  3. To send as a different From address (not only events@): uncheck Use Default Email Address and set From Email to {{from_email}}. Create that mailbox in cPanel, or add another EmailJS SMTP service for it. Reply-To must stay {{reply_to}}. No-reply campaigns also prefix the subject with NoReply: and start the body with “This inbox is not monitored…” so recipients can see that in the inbox list before opening.
  4. On the template, click Test It and send to a personal Gmail/Outlook. Then check EmailJS Email History and cPanel Track Delivery. A 200 OK from EmailJS is not the same as Gmail delivering the mail.
  5. In cPanel, enable SPF and DKIM for techhubafrica.org so other inboxes do not bury the mail.
  6. For the logo to appear, EmailJS Content must be exactly {{{message_html}}} (three braces). {{message}} is plain text and will hide the image.
  7. Optional campaign attachments need a paid EmailJS plan (Free cannot attach files). In the template Attachments tab, add Form File Attachment fields named attachment, then attachment_2, and so on. Set each Filename to {{filename}}, {{filename_2}}, matching the field. Keep files at 500 KB or less. Emails without files still send normally.
  8. EmailJS Free is 200 requests per month. After that, extra sends are ignored. For large recipient lists, use Batch send on Campaign Studio so the list is split and paced (for example every 2 minutes).

Open tracking

Off

After a campaign is sent, History can show who opened the email. This uses a tiny image in the HTML message. Recipients (or their mail app) must load images. Apple Mail Privacy Protection and similar features can mark mail as opened even if a person did not read it.

  1. Upload track.php with this Campaign Studio folder to cPanel (or another PHP host) so it has a public https:// URL.
  2. Paste that URL below. Example: https://techhubafrica.org/campaign/track.php.
  3. Keep EmailJS Content as {{{message_html}}} so the tracking image is included.
  4. Send a campaign, then open History and use Refresh opens.

Default organization logo

Inbox profile icon

The round picture next to the sender in Gmail is not the logo inside the email. Campaign Studio and EmailJS cannot set that avatar. Gmail draws a letter (for example “T”) unless the domain uses BIMI or the recipient saved you as a contact with a photo.

  1. Keep the logo in the message body with EmailJS Content set to {{{message_html}}}.
  2. For the Gmail circle to become the logo: set DMARC on techhubafrica.org to p=quarantine or p=reject (SPF and DKIM must already pass).
  3. Host a square SVG Tiny PS version of the logo at a public HTTPS URL (cPanel public_html), then add a BIMI DNS TXT record on default._bimi.techhubafrica.org pointing at that SVG.
  4. Gmail often also wants a Verified Mark Certificate (VMC) before it shows BIMI. Without that, many inboxes still show the letter icon.
  5. Quick workaround: ask people to save events@techhubafrica.org in Contacts and attach the logo as the contact photo.
